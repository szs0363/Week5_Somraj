# Week5_Somraj
Genome completeness pipeline for a single Beauveria bassiana assembly (GCA_014607475.1), running seqkit and BUSCO (hypocreales_odb10) via one script and merging results into a checksummed results_table.tsv. Built as a Week 5 exercise testing whether an AI coding agent can reproduce it byte-for-byte from the README and pinned environment alone.
